Información y Backup

Datos huérfanos — limpieza puntual

Desde ahora, cada eliminación (Booking, Producción, Hoja de Ruta, Propuesta, Roster) limpia detrás de sí misma automáticamente. Este botón revisa de una vez lo que se quedó suelto antes de estos arreglos (de cosas que ya borraste durante las pruebas): entradas del Calendario general, Evaluaciones de propuestas ya borradas, y entradas del Calendario del Roster — comprobando en cada caso si lo que referencian todavía existe.

Contadores de numeración

Muestra el último número usado este año para cada tipo de documento. Reiniciar un contador hace que el próximo empiece otra vez en 0001 — solo hazlo si estás seguro de que no se van a repetir IDs ya usados.

Cargando…

Copia de seguridad

Descarga un archivo con todos los datos de la plataforma (usuarios, bookings, producciones, roster, propuestas, clientes, venues, etc.) en formato JSON, por si necesitas restaurar algo o guardar una copia aparte de Firebase.

Restaurar desde backup

Sube un archivo .json generado con "Descargar backup completo". Sobrescribe los documentos que compartan ID con los que ya existen en la base de datos — no borra nada que no esté en el archivo. Úsalo solo si sabes lo que estás restaurando.
